## I make useful things for complicated lives.

I’m Luana, a product designer in life sciences and an indie builder. I work on care-aware, trauma-informed tools for women and caregivers, and explore how good product design can make a hard day a little easier to navigate.

## A few things I’ve made

| Project | What it helps with |
| --- | --- |
| [Trauma-informed UI](https://github.com/tropicgirlie/trauma-informed-ui) | Reusable interface patterns shaped around safety, autonomy and care. |
| [Cognitive Engine](https://github.com/tropicgirlie/cognitive-engine) | Evidence-led UX interventions for messy product problems. |
| [Carefolio](https://github.com/tropicgirlie/carefolio) | A care index dashboard with a documented score feed used by RemoteShe. |
| [Count Me In: Dyscalculia](https://github.com/tropicgirlie/count-me-in-dyscalculia-website) | A dyscalculia website concept and implementation. |
| [Closet, in rotation](https://tropicgirlie.github.io/closet-in-rotation/) | A local-first wardrobe tool for putting outfits together from clothes you own. |
| [What Leaves Home](https://tropicgirlie.github.io/what-leaves-home/) | A private household journal for noticing and reducing waste. |

## What I’m exploring

- Product design, UX research and AI-assisted workflows
- Care, cognitive load and accessible interfaces
- Small tools that help people do more with what they already have

I share works in progress as I build. The useful part is not only the polished screen, but the decisions, edge cases and revisions behind it.
